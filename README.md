# Go Microservice

## Brief

This microservice application build on learning purpose, the business logic on the application is about "match someone need a ride and someone want to share a ride".

the application build on top tools already common among developer start from go as primary language, rabbitmq as message broker and postgre as database

## How To Run The App

This application use docker and kubernetes as development tool and the tilt as the containerized tool.

Tool

- docker
- kuberetes / Minikube
- tilt

```bash
# To run the application
tilt up
```
